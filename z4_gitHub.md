## como guardar un proyecto en gitHub
- 1. estando en mi usuario de gitHub new > agrego el nombre> descripcion ,  public > Create repository
     es recomendable crearlo con el mismo nombre de la carpeta local para llevar un mejor orden
- 2. ya teniendo en mi local la carpeta creada y la consola abierta copio y pego todo el comando que me da gitHub
     sigo las indicaciones de la consola y listo proyecto cargado
